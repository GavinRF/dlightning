What this form sends

When you press send, we receive:

  • Your email and message, so we can reply
  • Tool name: which tool you wrote from
  • Interaction data: the answers and choices you made in the tool
  • Technical info:
    • Referrer (where you came from)
    • Browser type, to fix compatibility issues
    • Screen size and viewport, to improve the layout
    • Platform (Windows, Mac, etc.)
    • Time spent on the page
    • URL parameters

Why? This context helps us give better support and improve the tools based on how they're used. We never sell your data or use it for advertising.
